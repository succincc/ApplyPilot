READ THIS FIRST — WHY "START" DOES NOTHING RIGHT NOW
  This panel is a remote control. It does not apply to jobs, and it cannot.
  A web app in a browser tab cannot drive Chrome through a Workday login.

  Pressing Start writes one row to a "commands" table. A program called the
  engine, running on YOUR computer, picks that row up and does the actual
  work: searching boards, scoring jobs, rewriting your resume, filling forms.

  If the engine is not installed and running, Start writes a row that nobody
  reads, and nothing happens — exactly what you have been seeing. No amount
  of Lovable prompting changes this. Engine setup is at the bottom of this
  file.

  The header pill tells you which state you are in:
      "Engine offline"  -> nothing will happen when you press Start

Build a private, single-user job-search control panel called "ApplyPilot
Mission Control". It is a remote control for a separate program (the "engine")
that runs on my own computer. They communicate ONLY through the Supabase
database.

CRITICAL CONSTRAINT, applies to everything below:
This app must NEVER scrape job boards, call job-search APIs, generate resumes,
or submit applications. It only reads and writes Supabase tables. The engine
does all real work. If you think a feature needs to fetch a job or send an
application, you have misunderstood — write a row to the database instead.

No landing page. No marketing copy. No signup flow. Login goes straight to the
app. Mobile-first: I drive this from my phone.

PART 1 — DATABASE
--------------------------------------------------------------------------------

Run a migration on the connected Supabase project creating everything below.
Use "if not exists" everywhere. After creating each table, enable row level
security and add a policy granting all operations to the single authenticated
user (match the pattern of any existing table; if none exists, allow any
authenticated user).

create table if not exists jobs (
  id uuid primary key default gen_random_uuid(),
  url text unique not null,
  title text, company text, location text,
  salary_text text, site text,
  full_description text, application_url text,
  fit_score int, score_reasoning text,
  status text not null default 'discovered',
  skip_reason text, attention_reason text,
  confirmation_status text, confirmed_at timestamptz,
  resume_pdf_path text, cover_letter_path text,
  applied_at timestamptz, discovered_at timestamptz,
  updated_at timestamptz default now(),
  created_at timestamptz default now()
);

create table if not exists engine_status (
  id int primary key default 1 check (id = 1),
  online boolean default false,
  last_heartbeat timestamptz,
  current_stage text,
  run_started_at timestamptz,
  counters jsonb default '{}'
);
insert into engine_status (id) values (1) on conflict (id) do nothing;

create table if not exists commands (
  id uuid primary key default gen_random_uuid(),
  command text not null,
  payload jsonb default '{}',
  status text default 'pending',
  error text,
  created_at timestamptz default now(),
  handled_at timestamptz
);

create table if not exists search_presets (
  id uuid primary key default gen_random_uuid(),
  name text not null,
  is_active boolean default false,
  queries jsonb not null default '[]',
  locations jsonb not null default '[]',
  job_types text[] default '{fulltime}',
  salary_floor int,
  hours_old int default 168,
  boards text[] default '{indeed,linkedin,glassdoor,zip_recruiter,google}',
  extra_sources text[] default '{ats_registry,remote_boards}',
  exclude_titles text[] default '{}',
  exclude_companies text[] default '{}',
  no_go_patterns text[] default '{commission only,commission-only,100% commission,unlimited earning potential,door to door,door-to-door,1099 only,multi-level marketing}',
  min_score_auto_apply int default 6,
  review_band_low int default 4,
  daily_apply_cap int default 100,
  apply_workers int default 2,
  auto_run_hours numeric default 0,
  created_at timestamptz default now(),
  updated_at timestamptz default now()
);

create table if not exists profile (
  id int primary key default 1 check (id = 1),
  full_name text, preferred_name text, email text, phone text,
  address text, city text, province_state text, country text default 'United States',
  postal_code text, linkedin_url text, github_url text, portfolio_url text,
  salary_expectation text, salary_range_min text, salary_range_max text,
  years_of_experience text, education_level text, target_role text,
  legally_authorized text default 'Yes', require_sponsorship text default 'No',
  gender text default 'Decline to self-identify',
  race_ethnicity text default 'Decline to self-identify',
  veteran_status text default 'I am not a protected veteran',
  disability_status text default 'I do not wish to answer',
  resume_text text, resume_file_path text, resume_file_name text,
  resume_uploaded_at timestamptz, resume_parse_error text,
  resume_word_count int, resume_warnings text,
  updated_at timestamptz default now()
);
insert into profile (id) values (1) on conflict (id) do nothing;

create table if not exists questions (
  id uuid primary key default gen_random_uuid(),
  question_normalized text unique not null,
  question_raw text not null, answer text not null,
  answer_type text default 'text', confidence text default 'low',
  times_used int default 0, last_used_at timestamptz,
  source_job_url text, created_at timestamptz default now()
);

create table if not exists emails (
  id uuid primary key default gen_random_uuid(),
  gmail_id text unique not null,
  from_address text, subject text, snippet text, body_text text,
  received_at timestamptz, category text, classified_by text,
  job_id uuid references jobs(id) on delete set null,
  is_read boolean default false, created_at timestamptz default now()
);

create table if not exists target_companies (
  id uuid primary key default gen_random_uuid(),
  company text not null, ats text not null, board_token text not null,
  enabled boolean default true, created_at timestamptz default now()
);

create table if not exists interview_prep (
  id uuid primary key default gen_random_uuid(),
  job_url text unique not null,
  job_id uuid references jobs(id) on delete cascade,
  company text, title text, likely_questions text, talking_points text,
  questions_to_ask text, company_notes text,
  created_at timestamptz default now()
);

create table if not exists followups (
  id uuid primary key default gen_random_uuid(),
  job_url text unique not null,
  job_id uuid references jobs(id) on delete cascade,
  company text, title text, to_address text, subject text, body text,
  status text default 'draft', days_since int,
  created_at timestamptz default now()
);

create index if not exists idx_jobs_status on jobs(status);
create index if not exists idx_jobs_applied on jobs(applied_at desc);
create index if not exists idx_emails_received on emails(received_at desc);

Also: create a PRIVATE storage bucket named "artifacts", and enable Supabase
Realtime on the tables: jobs, engine_status, commands, emails.

================================================================================
  AFTER LOVABLE FINISHES: MAKING START ACTUALLY WORK
================================================================================

The panel will look empty and every screen will say "no data". That is
correct. The engine fills those tables.

ON YOUR COMPUTER (Windows, Mac or Linux — not your phone):

  1. Install Python 3.11+, Node.js 18+, Google Chrome, and the Claude Code
     CLI from claude.ai/code.

  2. Install the engine. BOTH pip lines are required — the second one is not
     optional, and skipping it is the most common reason discovery finds zero
     jobs:

       pip install applypilot pypdf
       pip install --no-deps python-jobspy
       pip install pydantic tls-client requests markdownify regex

  3. Get a free Gemini API key at aistudio.google.com. No credit card. Never
     click "Enable billing" — that deletes the free tier.

  4. Create the file ~/.applypilot/.env containing:

       GEMINI_API_KEY=your_key_here
       SUPABASE_URL=https://yourproject.supabase.co
       SUPABASE_SERVICE_KEY=your_service_role_key
       MAIL_ADDRESS=thomasdeluca0727@gmail.com
       MAIL_APP_PASSWORD=your_google_app_password

     Both Supabase values are in Supabase under Settings > API. Use the
     service_role key; it stays on your computer and never goes in the panel.
     The app password comes from myaccount.google.com/apppasswords.

     MAIL_ADDRESS must be the SAME address as the email in your panel
     profile. If they differ, employer confirmations arrive at an inbox
     nothing is watching, and your Inbox screen stays empty forever.

  5. Fill in the panel: Settings > My Profile (name, email, phone, work
     authorization), upload your resume, then Settings > Search Presets and
     create one with your job titles and locations, marked Active.

  6. Start the engine:

       applypilot doctor     every line should read OK
       applypilot verify     live-tests the job sources, email and Supabase
       applypilot sync       the bridge; leave this running

     Within 30 seconds the panel's pill turns green. You do NOT need to run
     "applypilot init" — the bridge creates everything from what you entered
     in the panel.

  7. Before trusting it with volume, prove one application:

       applypilot run all
       applypilot apply --dry-run --limit 1

     That fills a real form on a real posting and stops before submitting.
     Watch the Chrome window. If the fields look right, drop --dry-run.

  8. Then press Start in the panel and leave it alone.

IF START STILL DOES NOTHING
  - Pill gray/offline  -> the bridge is not running. Step 6.
  - Amber setup banner -> do exactly what it lists, then press Start again.
  - Runs but finds 0 jobs -> the terminal running the bridge prints the
    specific cause and the fix. Most often the second pip line from step 2
    was skipped, or the job titles in your preset are not words that appear
    in real postings.
